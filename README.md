# 💻 Aplicação Web com POO em PHP

Projeto web desenvolvido para praticar **Programação Orientada a Objetos em PHP**, reunindo diferentes módulos em uma única aplicação com formulários e processamento no back-end.

## 🚀 Funcionalidades

- 🧍 Cálculo e classificação de IMC
- 📦 Controle de estoque de produtos
- 🎓 Cálculo de média e situação escolar
- 💰 Cálculo de salário
- 📐 Classificação, perímetro e área de triângulos

## 🧩 Organização

A lógica é dividida nas classes `Pessoa`, `Produto`, `Nota`, `Funcionario` e `Triangulo`, explorando:

- atributos e métodos;
- encapsulamento;
- criação e uso de objetos;
- validação de dados;
- integração entre formulários HTML e PHP.

## 🛠️ Tecnologias

- PHP
- HTML5
- CSS3
- Bootstrap
- Slim Framework
- Composer
- Programação Orientada a Objetos

## 📁 Estrutura

O código principal está dentro da pasta `Projeto/`:

```text
Projeto/
├── public/          # Interface e ponto de entrada
├── src/             # Classes PHP
├── composer.json    # Dependências
└── composer.lock    # Versões das dependências
```

## ▶️ Como preparar o projeto

Entre na pasta do projeto e instale as dependências:

```bash
cd Projeto
composer install
```

Depois execute a aplicação em um servidor PHP/Apache apontando o diretório público para `Projeto/public/`.

## 🎯 Objetivo

Praticar a integração entre interface web e lógica orientada a objetos através de problemas cotidianos transformados em funcionalidades interativas.

Projeto desenvolvido durante a disciplina de PAW.
