# 💻 Aplicação Web com POO em PHP

Projeto web desenvolvido para praticar **Programação Orientada a Objetos em PHP**, reunindo diferentes módulos em uma única aplicação.

## 🚀 Funcionalidades

- Cálculo e classificação de IMC
- Controle de estoque de produtos
- Cálculo de média e situação escolar
- Cálculo de salário
- Classificação, perímetro e área de triângulos

## 🧩 Organização

A lógica é dividida nas classes `Pessoa`, `Produto`, `Nota`, `Funcionario` e `Triangulo`, explorando atributos, métodos, encapsulamento e validação de dados.

## 🛠️ Tecnologias

PHP • HTML • CSS • Bootstrap • Slim Framework • Composer • POO

## 🎯 Objetivo

Praticar a integração entre interface web e lógica orientada a objetos através de problemas cotidianos transformados em funcionalidades interativas.

Projeto desenvolvido durante a disciplina de PAW.
