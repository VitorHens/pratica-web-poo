Projeto PAW — Aplicação Web com Orientação a Objetos

Projeto acadêmico desenvolvido para a disciplina de PAW, com o objetivo de aplicar conceitos de programação orientada a objetos em uma aplicação web. O site reúne cinco módulos, acessíveis por um menu principal, com formulários para entrada de dados e apresentação dos resultados.

Funcionalidades

Calculadora de IMC: calcula o Índice de Massa Corporal a partir do peso e da altura, classificando o resultado em abaixo do peso, peso normal, sobrepeso ou obesidade.

Controle de estoque: permite informar cinco produtos, registrar entradas e saídas e calcular a quantidade disponível e o valor total em estoque de cada produto.

Média escolar: calcula a média de duas notas e apresenta a situação do aluno: aprovado, em recuperação ou reprovado.

Cálculo de salário: determina o salário final de um funcionário considerando as horas trabalhadas, as horas extras e seus respectivos valores.

Análise de triângulos: verifica se os lados informados formam um triângulo, classifica-o como equilátero, isósceles ou escaleno e calcula seu perímetro e sua área pela fórmula de Heron.

Organização do projeto

A lógica é organizada nas classes Pessoa, Produto, Nota, Funcionario e Triangulo, explorando encapsulamento, atributos, métodos e validação de dados. Os formulários se conectam aos endpoints responsáveis pelo processamento das informações.

A interface utiliza CSS e Bootstrap para estilizar os formulários e destacar os resultados. A aplicação foi projetada para execução em um servidor web local.

Objetivo

Praticar a integração entre interface web e lógica orientada a objetos, transformando problemas cotidianos em funcionalidades interativas.
